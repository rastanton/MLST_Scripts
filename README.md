# MLST_Scripts
**Scripts for MLST analysis**

MLST_Combination_Matcher_Exe.py: This script can generate all possible multilocus sequence types from an output from a set of MLST calls generated by the mlst tool (https://github.com/tseemann/mlst/tree/master) for a given species. This script can generate all possible MLST calls that can arise from multiple allele matches from paralogous genes (as can occur with the Acinetobacter baumannii Oxford scheme (https://pubmed.ncbi.nlm.nih.gov/20383326/).

The script requires an input of the file with the MLST calls (gnerated by the mlst tool) and a tab-delimited file of the scheme profiles.

Usage:
```
MLST_Combination_Matcher_Exe.py Input_MLST_Calls Input_MLST_Scheme_Profiles.txt
```

The output is a tab delimited text file with sequence ID and all possible MLST matches separated by a semicolon.

Allele combinations with no known matches are labeled as "NM".
